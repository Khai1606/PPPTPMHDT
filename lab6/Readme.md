## 🛠️ Hướng dẫn sử dụng

### 1. Cơ sở dữ liệu SQL Server
1. Mở phần mềm **SQL Server Management Studio (SSMS)**.
2. Mở file `QuanLyHoSoBenhAn.sql` và nhấn **Execute** (`F5`) để khởi tạo CSDL và bảng.

### 2. Xem sơ đồ thiết kế
1. Truy cập [diagrams.net](https://app.diagrams.net/).
2. Chọn `File` -> `Open From` -> `Device...` và chọn file `SODOBENHAN.drawio`.
