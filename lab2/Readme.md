## 🚀 Hướng Dẫn Sử Dụng

1. **Xem Báo Cáo:** Mở tệp `.docx` bằng Microsoft Word để đọc nội dung báo cáo hoàn chỉnh.
2. **Cơ Sở Dữ Liệu:** Mở tệp `QuanLyThuVien.sql` bằng *Microsoft SQL Server Management Studio (SSMS)* và chạy script để khởi tạo CSDL.
3. **Sơ Đồ Thiết Kế:** 
   * Truy cập [draw.io](https://app.diagrams.net/) và mở các tệp `.drawio` tương ứng để chỉnh sửa sơ đồ.
   * Xem trực tiếp các hình ảnh sơ đồ đã xuất trong thư mục `png/`.
